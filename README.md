Python agent runtime. Turn loop, tool dispatch, MCP, skills, memory, retrieval, a FastAPI streaming gateway, eval suites with judge metrics and regression gates, and OpenTelemetry traces over prompts, tool calls, and turns. MIT. I am the primary author.

### [MonkeySkills](https://github.com/human-plus-machine/monkeyskills)

Structured agent skills that take a product from idea to a shipped change, with resumable state and handoffs between skills. Works in Cursor and Claude Code. MIT.
